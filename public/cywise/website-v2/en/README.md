# Cywise — FastBootstrap neo-brutalist redesign

Prototype front-end statique du redesign Cywise.

## Stack

- HTML5
- FastBootstrap 2.2.0
- Bootstrap 5.3.2 bundle pour les composants interactifs
- CSS personnalisé
- JavaScript léger
- Google Fonts: Space Grotesk et IBM Plex Mono

## Lancer le site

Ouvrez simplement `index.html` dans un navigateur.

Pour un serveur local :

```bash
python -m http.server 8000
```

Puis ouvrez `http://localhost:8000`.

## Structure

- `index.html` : contenu et structure.
- `styles.css` : direction neo-brutalist.
- `app.js` : comportement mobile simple.

## Remarque

Le site est un prototype de redesign.
Les liens vers les pages internes sont encore des placeholders.

## Pages ajoutées

- `solutions/index.html` et 6 pages solution.
- `for-whom/index.html` et 5 pages audience.
- `use-cases/index.html` et 6 pages cas d'usage.
- `blog/index.html`.
- `pricing/index.html`.

Les entrées principales et les sous-menus sont reliés aux nouvelles pages.
