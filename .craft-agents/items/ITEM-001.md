# ITEM-001: Ajout du lien Société dans le menu

Owner: Junie
Base: main
Branch: item/ITEM-001
Status: ready

## Description

Ajouter un lien vers la page "Société" dans le menu de navigation principal, entre "Cas d'usage" et "Blog".
Le lien doit être disponible en français ("Société") et en anglais ("Company").

## Acceptance

- [ ] Un lien "Société" est présent entre "Cas d'usage" et "Blog" sur la version française.
- [ ] Un lien "Company" est présent entre "Use cases" et "Blog" sur la version anglaise.
- [ ] Les liens pointent vers les routes `website.company` (FR) et `website.en.company` (EN).
- [ ] Le lien est visible sur desktop et mobile.
