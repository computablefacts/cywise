## Description

Retirer toutes les références, pages, liens et contenus relatifs à la PSSI (Politique de Sécurité des Systèmes d'Information) du site web corporate.
Cela inclut les pages de présentation, les entrées de menu, les sections du footer et les mentions dans les documents de base.

## Acceptance

- [x] La page dédiée à la PSSI n'est plus accessible.
- [x] Les liens vers la PSSI dans le header et le footer ont été supprimés.
- [x] Les références à la PSSI dans le README et autres documents de documentation sont retirées.
- [x] Les traductions liées à la PSSI sont nettoyées.
