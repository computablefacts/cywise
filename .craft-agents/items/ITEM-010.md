# ITEM-010: Improve Git commit message format

- Owner: Junie
- Base: main
- Branch: item/ITEM-010
- Status: in_progress

## Description

Improve Git commit messages generated by CraftAgents.
Each specification must have at least one dedicated commit.
The commit message must follow a specific format including the Spec ID and the requirement description.

## Acceptance

- [ ] DOCTRINE.md defines the new commit message format.
- [ ] The format includes the Spec ID in the header: `feat(ITEM-NNN-SMM): Title`.
- [ ] The format includes the Spec requirement in the body.
- [ ] The requirement for one commit per Spec is explicitly stated.
